# 未着手アイデア台帳（IDEA_BACKLOG）

このファイルは、未着手/一部実装/実装済みのアイデアを見失わないための台帳です。  
この台帳は実装順を確定するものではありません。  
正式な現在仕様は `PROJECT_SPEC.md`、優先順位は `ROADMAP.md` を参照してください。  
アイデアが実装済みになったら「状態」を更新し、関連docsへのリンクも更新してください。

---

## 使い方

- 状態ラベルは次の6種で統一します。  
  `未着手` / `一部実装` / `実装済み` / `保留` / `要設計` / `後続拡張`
- 各項目は、可能な範囲で次を記録します。  
  アイデア名 / 状態 / 概要 / 実現済みの部分 / 未実装の部分 / 必要になりそうな基盤 / 関連docs / 次に切るならどんなMVPか

---

## 要注意: 埋もれやすいアイデア

### ランキング / トレンド / 指標系

- アイデア名: ランキング / トレンド / 指標系（今遊ばれているゲーム、人気のゲーム、公開ゲームの人気順/プレイ数順、今使われているアセット、アセットのお気に入り順/閲覧数順/使用数順/人気順、作者ダッシュボード/分析）
- 状態: `一部実装`
- 概要: カウント系の土台はあるが、ランキング提供や期間集計、分析UIは未整備。
- 実現済みの部分:
  - `GameProject.viewCount` / `playCount` は実装済み
  - 公開ゲーム詳細/プレイ時のカウントMVPは実装済み
  - アセット `favoriteCount` 表示MVPは実装済み
  - `GameAssetReference` / `GameCharacterReference` は実装済み
  - トップページの新着コンテンツ枠MVPは実装済み（ランキングではない）
- 未実装の部分:
  - 人気順 / プレイ数順 / お気に入り順 / 使用数順ソート
  - ランキングAPI
  - 「今遊ばれている」など期間集計
  - 「今使われているアセット」表示
  - ユニーク閲覧/ユニークプレイ
  - イベントログ
  - 日別集計
  - 作者ダッシュボード
  - 不正/連打対策
- 必要になりそうな基盤:
  - 集計期間の定義
  - event log / play session / view session
  - 使用数の定義（公開ゲームのみか、非公開も含めるか）
  - Like / Shelf 分離後の指標定義
  - キャッシュ/集計バッチの要否
- 関連docs:
  - `docs/ROADMAP.md`
  - `docs/PROJECT_SPEC.md`
- 次に切るならどんなMVPか:
  - `公開ゲーム 人気順/プレイ数順ソート MVP`
  - `アセット使用数 usedInGameCount 定義MVP`
  - `ランキング集計基盤 設計メモMVP`
  - ただし本格ランキングは焦らず、先に定義を固める
